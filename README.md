Converts images into equations that can be represented in the desmos graphing calculator.

<img width="670" height="338" alt="image" src="https://github.com/user-attachments/assets/39686629-63ae-47cd-b593-092c7f00214e" />

Images are segmented into colored segments using K-Means clustering.

Neural networks are then fitted to each cluster using logistic regression, and the results are graphed in desmos.
